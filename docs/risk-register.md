# 风险清单

该清单记录当前实现前后的主要风险；状态会随每个阶段验收更新。

| ID | 风险 | 影响 | 当前控制 | 状态/后续 |
| --- | --- | --- | --- | --- |
| R-01 | 检测漏检被误算成识别错误 | 错误调参和错误结论 | 报告分开统计检测与识别 | V0.1 基准验证 |
| R-02 | 模型标签错位或作品 Tag 缺失 | 错误角色名、错误分类 | 启动时校验维度、类别和白名单交集 | 待真实模型安装验证 |
| R-03 | 侧脸、背面、遮挡、相似角色混淆 | 错误自动分类 | margin、多裁剪一致性、强制待确认 | 用真实基准校准 |
| R-04 | 源文件被意外移动/覆盖 | 数据丢失 | V0.1 只读；后续 dry-run、执行前指纹校验、冲突序号 | V0.4 专项测试 |
| R-05 | 跨卷移动中途失败 | 源/目标不一致 | 复制→校验→删除源，失败保留源 | V0.4 专项测试 |
| R-06 | 删除相似图不可恢复 | 永久数据丢失 | 人工确认、回收站、无法回收时二次确认 | V0.5 专项测试 |
| R-07 | 模型权重或 Token 进入 Git/日志 | 隐私、许可证和密钥泄露 | `.gitignore`、本地锁文件、CI secret、文档警告 | 持续审计 |
| R-08 | 上游权重许可证/访问条件变化 | 无法合法分发 | 不捆绑受控权重，发布前重新核对 | 发布前复核 |
| R-09 | Worker 崩溃阻塞 UI | 任务中断、状态不一致 | 进程隔离、health check、可恢复任务状态 | 阶段 0 验收 |
| R-10 | 大图库重复推理导致卡顿 | 用户体验、资源耗尽 | 后台 Worker、缓存键绑定模型/策略、暂停/取消 | V0.2 验证 |
| R-11 | 输出目录被再次扫描 | 重复移动和计划膨胀 | 输出/缓存/显式排除目录过滤 | V0.2 验证 |
| R-12 | 自动更新签名配置错误 | 安装失败或供应链风险 | 私钥只读 secret，公钥/端点不伪造，发布前验证 | 发布流程建立后复核 |

风险关闭必须有可复现测试或审计证据，不以“代码路径存在”代替验证。
