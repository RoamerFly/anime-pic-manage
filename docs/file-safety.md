# 文件安全与可回退操作

## 不可逆操作边界

扫描和识别只读源图片，并写数据库、缓存和分类计划。程序不得“识别一张就移动一张”。只有用户明确点击执行，并通过执行前检查后，才允许移动、复制或重命名。相似图片删除也必须由用户明确触发，优先进入系统回收站。

## Dry-run 分类计划

每条计划至少包含：源路径、源文件指纹、缩略图引用、人物数、角色 Tag/显示名/置信度、业务状态、目标目录、目标文件名、操作类型、冲突和警告。计划不是执行记录，`planned` 不得被解释为 `applied`。

默认目录：

```text
输出目录/
├─ 角色显示名/
├─ 多角色/
├─ 待确认/
├─ 未识别/
└─ 无人物/
```

多人物图片统一进入 `多角色`；角色按左到右、从上到下稳定排序，同一角色默认只在文件名出现一次。扩展名保持原样。冲突使用 `_002` 等可预测后缀，绝不覆盖已有路径。

## 执行前检查

真正执行每项操作前，重新验证：

1. 源文件仍存在且指纹未变；
2. 目标目录在允许的输出目录范围内，且不等于源目录中的排除目录；
3. 目标路径不存在或已通过安全冲突策略改名；
4. 磁盘空间、读写权限和路径长度可用；
5. 移动/复制模式明确；
6. 跨卷移动将执行“复制→校验→删除源文件”，校验失败时保留源文件。

任何检查失败都应跳过该项并记录可理解的错误，不继续覆盖或删除。

## 事务与撤销

真实操作记录源路径、目标路径、操作类型、开始/完成时间、源/目标指纹、结果、错误和撤销状态。异常退出后，启动恢复检查应以磁盘事实为准，不能只依据数据库把操作标为成功。撤销应以文件存在性和指纹校验为前置条件；发现目标被外部修改时停止并要求人工处理。

## 扫描排除

递归扫描必须排除输出目录、应用数据/缓存目录以及用户明确排除的目录，避免已分类图片再次进入计划。路径比较应规范化、处理大小写和符号链接策略；测试需覆盖中文路径、空格、长路径、特殊字符、跨卷和输出目录嵌套。

## 删除安全

删除相似图片只允许在相似度候选组中由用户选择，UI 需展示大图、路径、尺寸、格式、大小、相似类型和分数。优先调用系统回收站；无法回收时必须二次确认，并明确说明不可恢复风险。没有用户确认、没有完整计划或指纹已变化时禁止删除。

## 测试要求

至少覆盖空目录、权限拒绝、同名冲突、源文件消失、源文件变化、跨卷失败、目标目录在扫描目录内、长路径和应用异常退出。测试应使用临时目录和合成文件，不使用真实用户图库。
